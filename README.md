# dev-window — «Вікно розробки»

Автономний плагін AX/Server Hub (контракт `plugin-tab`, варіант A: окремий процес + `iframe`). Лише читання: показує задачі з `docs/tasks/inbox` і локальні гілки `task/*` репозиторію. Не запускає команд (крім `git for-each-ref`), не пише на диск, не використовує токенів. Node 22, без залежностей.

## Запуск

```
DEVWIN_REPO=/шлях/до/репо DEVWIN_PORT=8811 node server.js
```

- `DEVWIN_PORT` — порт (типово 8811, 1024–65535); слухає лише `127.0.0.1`.
- `DEVWIN_REPO` — корінь репозиторію. Без нього API повертає порожні списки з полем `error`.

## Ендпоїнти (лише GET)

| Шлях | Опис |
|---|---|
| `/` | українська HTML-сторінка, без зовнішніх ресурсів, з CSP |
| `/health` | `{ok, module, version, run_as:"session"}` |
| `/api/tasks` | `*.md` з `docs/tasks/inbox` (до 100 файлів, до 32 КБ кожен; симлінки й вихід за каталог ігноруються) |
| `/api/branches` | гілки `task/*` через `git for-each-ref` (execFile без shell, таймаут 5 с, до 200) |
| `/logs` | кільцевий журнал останніх 200 подій |

Запити з чужим заголовком `Host` (захист від DNS rebinding) відхиляються з 403, не-GET методи з 405.

## Підключення до Hub

`module.json` (schema 1, `kind: "plugin"`, `run_as: "session"`) кладеться в `<каталог плагінів Hub>/dev-window/module.json`. Вкладка «Вікно розробки» показується в `iframe` з `http://127.0.0.1:8811/`. Артефакт у маніфесті заглушка (нульовий sha256), заповнюється під час випуску релізу (`module-release`).
